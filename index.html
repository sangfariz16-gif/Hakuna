How it works

🐷 Minted by agents, not by clicking

Only wallets holding a Binance .ai Agent ID can mint. The check happens on-chain — no ID, no mint. Every mint is a random draw from the remaining pool.

01

Get your Agent ID

Create a Binance Agentic Wallet in the Binance app and claim your free .ai Agent ID (SPACE ID). One ID per wallet.

02

Point your agent at the mint

Your agent calls mint(uint256 quantity) on the contract — or mint from this page. First mint per wallet is free (gas only), then $0.69 for mints #2–17, $0.85 for #18–32, $1.20 for #33–44 in BNB, up to 44 per wallet.

03

Receive your pig — a mystery draw

Your Hakuna Agent NFT lands in your wallet on BNB Chain. The token is drawn at random from the remaining pool — a rare pig gets easier to pull as the supply runs out. Each paid mint also earns 120,000 HAKU* — claimable after mint.

*Token economics — HAKU token is live at 0x284665A4a1b62aC24329dAC30671CBB42817eB13.

FAQ

Questions, answered honestly

If it is not written here, it is not promised.

Is the first mint really free?

Yes. The first mint per wallet is free — you only pay BNB Chain gas (a few cents). After that, mints #2–17 cost $0.69, #18–32 cost $0.85, and #33–44 cost $1.20, in BNB at the oracle rate. Max 44 mints per wallet.

Do I need an Agent ID to mint?

Yes. Minting is gated to wallets holding a Binance .ai Agent ID (SPACE ID). The check happens on-chain — no ID, no mint. Buying and collecting afterwards is open to everyone.

What is HAKU?

HAKU is the bonus token for paid mints: 120,000 HAKU per paid mint, claimable on-chain. Total supply 1B — 540M bonus pool, 460M treasury. Free mints earn no HAKU. HAKU is a bonus for minters, not an investment — no return is promised.

When does mint open?

Mint opens once the contracts deploy — the deploy happens on the project’s go-ahead. First mint per wallet is free, then $0.69 / $0.85 / $1.20 in BNB, up to 44 per wallet.

Which wallet can I use?

Binance Agentic Wallet, or any BNB Chain wallet holding a .ai Agent ID. Your agent mints through the contract; humans can mint from this page once it is live.

What do I actually get?

A Hakuna Agent NFT (BEP-721 on BNB Chain) — 1 of 4,444, one of 5 pig guardians, drawn at random, with its tier written into the token metadata.
